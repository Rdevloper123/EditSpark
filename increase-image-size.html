Frequently Asked Questions (FAQ)

Q1. Output file target range se thoda kam kyu hai?

Strict systems me standard rules hote hain jo upper-bound hit hote hi file upload block kar dete hain. Isliye structural engine output ko humesha target limit ke safe bounds ke andar (~95-98%) hi optimize karta hai.

Q2. Kya PNG files ki quality reduce hoti hai?

PNG lossless compression format hai jisme image bit depth ya profile change se data direct compress nahi hota. Isliye PNG me target limit hit karne ke liye structural level par resolution scaling constraints apply kiye jate hain.
